# E2E テストのカバレッジ不足

## 概要

現在の E2E テストは基本的な通信テストのみで、各プロトコルの機能を網羅していない。

## 現状

### QUIC レベル (充実)

- [x] 双方向ストリーム通信
- [x] サーバー起点ストリーム
- [x] DATAGRAM 通信

### WebTransport H3

- [x] 基本的なストリーム通信
- [ ] DATAGRAM 通信
- [ ] 単方向ストリーム (unidirectional)
- [ ] サーバー起点ストリーム
- [ ] 複数ストリーム同時使用
- [ ] ストリーム close/reset

### WebTransport H2

- [x] 基本的なストリーム通信
- [ ] 単方向ストリーム (unidirectional)
- [ ] サーバー起点ストリーム
- [ ] 複数ストリーム同時使用
- [ ] ストリーム close/reset
- (注: HTTP/2 は DATAGRAM 非対応)

### HTTP/3

- [x] 基本的なリクエスト/レスポンス
- [ ] POST リクエスト + ボディ送信
- [ ] 複数リクエスト同時処理

### HTTP/2

- [x] 基本的なリクエスト/レスポンス
- [ ] POST リクエスト + ボディ送信
- [ ] 複数リクエスト同時処理

## 期待する動作

各プロトコルの主要機能が E2E テストでカバーされていること。

## 優先度

中 - 基本機能は動作確認済み、追加機能のテストが不足
